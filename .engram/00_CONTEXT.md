# Contexto del Proyecto: Brinines AI

Sistema de gestión comercial y conversacional para Brinines Panadería (Tucumán).
- Arquitecto: ChatGPT (decisiones estratégicas y arquitectónicas).
- Ejecutor: OpenCode (implementación, edición, Git, clasp).
- Entorno: Google Apps Script.
- Persistencia: Google Sheets.

Flujo: ManyChat/Entrada -> Webhook -> Apps Script -> Gemini -> Sheets.
